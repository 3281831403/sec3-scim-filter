同步服务用过滤表达式查用户，攻击者往条件里塞了一个或运算，把整租户的用户都拉了出来：过滤表达式必须按语法解析而不是拼接；属性必须白名单；逻辑运算必须按优先级；比较必须按类型；复杂度必须有上限；批量查询各请求独立。不变量：任何表达式都不会扩大查询范围；同一表达式两次解析结果相同。

表达式约定

属性名区分大小写，只允许 userName displayName active age department。
比较符只允许 eq ne co sw ew gt ge lt le pr。
字符串字面量用双引号包裹，逻辑词和比较符用小写。
括号必须成对出现，空表达式不是有效查询。
属性存在性比较使用 pr，不再附加字面量。

优先级与类型

逻辑运算的优先级从高到低为 not and or，同级从左到右结合。
数值只按数值大小比较，布尔只与布尔比较，字符串只做字符串运算。
有序比较使用数值，包含与前缀后缀匹配使用字符串。
类型不匹配的条件不产生匹配，也不抛出求值异常。

复杂度与批量

表达式树深度不得超过 8。
批量查询逐个解析每个请求，请求之间不得共享解析结果或可变状态。
单条请求失败或无效时，只影响该请求的结果。

验收

任何合法表达式都不会扩大调用方给定的查询范围。
同一表达式重复解析必须得到相同结构。
公开测试覆盖词法切分、语法解析、属性白名单、类型求值和批量请求隔离。
